Introduction
============

``nson`` is a header-only C++23 library that implements convenience functions and structures in the
C++ standard library with focused, well-tested helpers. It plays a
similar role to Google's `Abseil <https://abseil.io/>`_.

The name **nson** is an abbreviation of *nia sono*, which in Esperanto means "our
sound". The library is developed and used extensively by
`us4us Ltd <https://www.us4us.eu>`_ in its C++ codebase.
