API Reference

The public API are located entirely in the nson namespace.

Public headers

Every header is extensionless and included as #include <nson/name>.

Header

Contents

nson/bits

Bit manipulation helpers (nson::bits).

nson/compiler

Compile-time detection of the compiler in use (nson::COMPILER).

nson/concepts

Concepts describing which types nson::to_string and nson::join accept.

nson/features

Compile-time feature flags for the current toolchain (nson::features).

nson/math

constexpr numeric helpers that the standard library lacks, such as integral pow.

nson/reflection

Compile-time type names (nson::reflection::type_name).

nson/string

String conversion and formatting: to_string, join, trim.

nson/type_traits

Assorted type traits, such as safe_underlying_type.

nson/void_safe

Type traits that tolerate void (nson::void_safe).

template<std::ranges::range C>
inline std::string join(const C &values, const std::string &separator = ", ")

Joins the given range of values with the given separator, using nson::join specializations.

Template Parameters:

C – type of the container (e.g. std::vector<some_type>, gsl::span<some_type>, std::set<some_type>, etc.)

Parameters:

  • values – container of values to convert

  • separator – string to separate the values in the resulting string. By default, it’s “, “

Returns:

a string containing all the values from the input container separated by the given separator

template<auto base, std::size_t exp>
constexpr auto pow = pow_impl<decltype(base), base, exp>::value

A constant expression that computes the power of a base raised to an exponent at compile time.

Useful, as:

  1. std::pow isn’t constexpr until C++26;

  2. std::pow provides no integral variant.

Template Parameters:

  • base – The base value.

  • exp – The exponent value.

Return:

The result of base raised to the power of exp.

template<typename T, bool = std::is_enum_v<T>>
struct safe_underlying_type
#include <type_traits>

A type trait that provides a safe underlying type for a given type.

If the type is an enum, it will provide the underlying type. Otherwise, it will provide the type itself.
